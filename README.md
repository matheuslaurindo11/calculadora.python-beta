# Calculadora Python 🧮

**Status: Beta — ainda em desenvolvimento.**

Uma calculadora simples que estou fazendo para praticar Python e lógica de programação.

Ainda estou aprendendo a linguagem, então o código pode mudar bastante com o tempo. Pretendo fazer algumas melhorias e adicionar novas funcionalidades conforme for evoluindo nos estudos.

## Tecnologias
- Python 3
- PyCharm

## Como executar

Clone o repositório:

```bash
git clone https://github.com/matheuslaurindo11/calculadora.python-beta.git
```

Entre na pasta do projeto:

```bash
cd calculadora.python-beta
```

Execute a calculadora:

```bash
python3 calculadora.py
```

## Sobre o projeto

Esse é um dos meus primeiros projetos em Python. A ideia é continuar mexendo nele enquanto aprendo coisas novas e melhorar o código aos poucos.
